ChatGPT AI — Privacy Policy

1. Introduction

This Privacy Policy explains how ChatGPT AI, developed by benjithepro ("the Chatbot"), collects, uses, and protects information when you use the Chatbot on Discord. By using the Chatbot, you agree to the practices described in this policy.

2. Information We Process

  • The Chatbot may process message content sent by users in channels where the bot is used.
  • This information is used only to understand user input and generate AI responses.
  • The bot may also process basic metadata such as Discord user IDs, server IDs, and channel IDs required for functionality.

3. How Information Is Used

  • To generate AI-powered responses to user messages.
  • To maintain short-term conversation context.
  • To ensure the proper functionality and stability of the Chatbot.
  • To prevent abuse, spam, or misuse of the service.

4. Data Storage

  • Message content is generally processed temporarily in memory.
  • The Chatbot does not permanently store message content unless required for a specific feature.
  • Any stored data is limited to what is necessary for the Chatbot to function.

5. Data Sharing

  • The Chatbot does not sell or share personal data with third parties.
  • Some requests may be processed through external AI APIs to generate responses.
  • These services only receive the data required to generate the response.

6. AI and Machine Learning

  • User messages are not used to train machine learning models.
  • Messages are processed only to generate responses.
  • No user content is used to improve or retrain AI systems.

7. User Control

  • Users control when they interact with the Chatbot by sending messages to it.
  • Server administrators may disable or remove the Chatbot at any time.
  • Users may stop interacting with the Chatbot if they do not wish their messages to be processed.

8. Security

  • Reasonable measures are taken to protect data processed by the Chatbot.
  • However, no system can guarantee absolute security.
  • Users should avoid sharing sensitive or personal information with the Chatbot.

9. Changes to This Policy

  • This Privacy Policy may be updated periodically.
  • Continued use of the Chatbot after updates means you accept the revised policy.
  • Users are encouraged to review this page regularly.

By using ChatGPT AI, you acknowledge that you have read and understood this Privacy Policy.
